**Same verdict, different culprit: which control decided? Attribution and enforcement points for AI agent payments**, preprint draft v0.3.

Jayath de Silva ([ORCID 0009-0007-1855-4158](https://orcid.org/0009-0007-1855-4158)) · Independent

When controls can only make an AI agent's payment verdict stricter, the order they run in never changes the verdict, but it does change which control the record names whenever two of them refuse. The paper argues that agent payment governance should require that record, and maps where a spending control can sit on an x402 payment: pre-tool hook, client spend controls, custodial signer, agent gateway, seller, facilitator.

New in v0.3:

- A new title; the previous one is kept as the subtitle.
- **Table 0** at the front: what the paper concedes to prior work and what it claims, with the closest prior art and what that prior art does not do.
- **Appendix A:** install, govern a payment, see which control decided, run the twenty-attack benchmark and the conformance suite. Every command was run from a clean install before release.
- Links to every repository and record; "Section 5" in place of the section sign.

`paper.pdf` attached (23 pages). Not peer reviewed. Drafting and figures used an AI assistant; the author checked every claim and source.
